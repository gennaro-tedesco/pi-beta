`pi-beta` is an interactive home dashboard for Raspberry Pi systems and little LCD or e-ink screens, designed to show house widgets and display photo loops. It is your home piece of awesomeness.

## Installation

Executables exist for Raspberry Pis (`linux-arm64`) and Apple Silicon (`macos-arm64`) architectures: the quickest installation method is to download the latest release executable from the [release page](https://github.com/gennaro-tedesco/pi-beta/releases) and install it on the corresponding machine. Otherwise the codebase runs as wails application which you can clone and locally run with `wails dev`.

## Widgets

Four widgets are provided by default:

- photos
- weather
- calendar
- networks and processes

Interaction with each widget is self-explanatory via touch screen or point click. Return to the home dashboard by tapping the `pi-beta` logo on the top left corner.
